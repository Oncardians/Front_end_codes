# 🎨 Frontend Geliştirme Arşivi & Portfolyo Projeleri

Bu depo (repository), frontend geliştirme yolculuğum boyunca temel kavramları pekiştirmek, modern arayüzler tasarlamak ve pratik yapmak amacıyla geliştirdiğim projelerin derlenmiş bir koleksiyonudur. 

Her bir klasör, farklı bir arayüz problemini, tasarım yaklaşımını veya frontend teknolojisini deneyimlediğim bağımsız bir çalışmayı temsil etmektedir.

---

## 📂 Proje Dizini

| Klasör Adı | Proje Açıklaması | Kullanılan Teknolojiler |
| :--- | :--- | :--- |
| **`proje-1-klasor-adi`** | Projenin kısa açıklaması (Örn: Responsive e-ticaret ürün kartı ve sepet arayüzü) | `HTML5` `CSS3` `JavaScript` |
| **`proje-2-klasor-adi`** | Projenin kısa açıklaması (Örn: Hava durumu API entegrasyonlu web uygulaması) | `React` `Tailwind CSS` `REST API` |
| **`proje-3-klasor-adi`** | Projenin kısa açıklaması (Örn: Kişisel blog veya landing page klonu) | `HTML5` `SCSS` `Flexbox/Grid` |

*(Not: Kendi klasör isimlerine ve kullandığın dillere göre bu tabloyu çoğaltabilirsin.)*

---

## 🛠️ Öne Çıkan Kazanımlar ve Odak Noktaları

* **Responsive (Duyarlı) Tasarım:** Farklı ekran boyutlarına (mobil, tablet, masaüstü) uyumlu esnek arayüz mimarileri.
* **Temiz ve Modüler Kod:** Okunabilir, sürdürülebilir CSS/SCSS ve JavaScript yapılandırmaları.
* **DOM Manipülasyonu & Etkileşim:** Kullanıcı deneyimini artıran dinamik arayüz bileşenleri ve form doğrulamaları.
* **API Entegrasyonları:** Asenkron veri çekme ve dinamik içerik yönetimi pratikleri.

---

## 🚀 Projeleri Yerelde Çalıştırma

Herhangi bir projeyi kendi bilgisayarınızda incelemek için:

1. Bu depoyu klonlayın:
   ```bash
   git clone https://github.com
   ```
2. İlgili proje klasörüne gidin:
   ```bash
   cd REPO_ADIN/proje-1-klasor-adi
   ```
3. Statik projeler için `index.html` dosyasını tarayıcıda açabilir veya framework tabanlı projeler için `npm install` & `npm start` komutlarını çalıştırabilirsiniz.
